2. Using backticks creates a type of string called a template literal that interprets ${} as "put the value of whatever variable is in the brackets here." This is extremely useful because you can write easy-to-read sentences in a console that have variables built in, or presumably strings on a webpage since JS is used in web development. You can write things like "Website version: 1.0.0/Plugin last updated: 1/25/2014" to a browser console that can be very useful for debugging problems. That's not a great example but you get the point.
